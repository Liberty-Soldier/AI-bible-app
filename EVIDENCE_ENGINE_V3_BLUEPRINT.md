\# Evidence Engine V3 Blueprint



\## Purpose

Evidence Engine V3 is the permanent Scripture evidence compiler for:

\- BibleIQ

\- Ask Scripture

\- Context Tree

\- Future AI reasoning



\## Core Rule

Evidence is data.

English is rendering.

AI is explanation.



\## Forbidden

\- No manually curated entities

\- No Strong's-number special cases

\- No person-only logic

\- No English summaries stored as evidence

\- No giant generated files imported into runtime



\## Build Flow

1\. Canonical Scripture inputs

2\. Occurrence extraction

3\. Entity evidence

4\. Relationship evidence

5\. Event evidence

6\. Theme evidence

7\. Timeline evidence

8\. Graph indexes

9\. Runtime split files

10\. Renderers



\## Runtime Rule

The app may only load small split evidence files and small indexes.
