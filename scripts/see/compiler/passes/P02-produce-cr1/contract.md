# P02 — Produce CR1 Witness Universe

Consumes:
- CR0 Canonical Universe
- SourceUniverse

Produces:
- CR1 Witness Universe

Purpose:

Attach every available witness to every canonical verse.

Owns:

- witness availability
- source metadata
- canonical witness mapping

Does NOT Own:

- source tokens
- alignments
- occurrences
- evidence
- entities
- relationships
- events
- themes

Quality Gate

Every canonical verse must know which witnesses exist.
