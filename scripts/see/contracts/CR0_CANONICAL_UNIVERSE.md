\# CR0 — Canonical Universe

It defines the normalized structure that all witnesses attach to.



CR0 does not contain evidence.

\- source availability map

\- occurrences

\- evidence

\- entities

\- relationships

\- events

\- themes

\- renderer output

\- AI explanations

Canonical structure is immutable.



Sources attach to it.
